# Four supplementary measurements

The unit is a frozen, score-ordered matrix from the expansion campaign. Execute the four studies in order on a single logical CPU with the frozen C++ binaries, serial child processes, and warm filesystem cache. A timed invocation averages repeated kernel calls over a 20 ms minimum. A separate clock in each invocation measures opening and reading a dense matrix, allocating it and building column adjacency. Each invocation returns the complete probability vector. The driver retains it, the observed fallback reason, repeat count, clocks and method order. Each block uses three rounds, with order shuffled using a deterministic per-round seed. These four studies reuse inputs from the graph-query campaign.

* M5/Q4. Use every fresh larger OGB case and all three scale cases at length 2048. Time all controls originally eligible for the corresponding timing envelope. On each case take its minimum control median and sparse median, and use the median of the three sparse-invocation loader measurements as a common paid load for both. Report per-case baseline inference fraction, sparse loader fraction, and ratio of total times. Summarize by medians across cases. A process start, output formatting, retrieval, and graph extraction are outside both clocks.
* Q3. Use every small fresh Cora and OGB case. Reuse the original ordered graph and the same underlying uniform quantiles. In the alternate arm convert original first-hop probabilities by 0.1+0.8(a−0.25)/0.55 and supported second-hop probabilities by 0.1+0.8(b−0.4)/0.5. Zeros remain zero. Interleave the two arms and all five eligible methods, computing each arm's speedup using its own best control. Check each vector against its arm's direct output. Report median paired change and wins as well as the separate arm medians.
* Q8. Use the same 50 small fresh cases and the 25 fresh larger OGB cases. Generate uniform markers in row-major support order with NumPy PCG64(701900+case index). Replace a supported b with 1 when its marker is below 0, .01, .05 or .20, preserving all other values. Masks are nested. Record trigger fraction, number of marked edges and paired time relative to the zero-dose sparse call, by stratum and dose. Time the frozen sparse dispatcher. Check all small endpoint vectors against first-hop enumeration as an independent check outside the timing schedule. The larger endpoint cases have no general enumeration check.
* Q9. Use every scale case with L=1024 or 2048. Check one-based ranks L/2, 3L/4 and L. Evaluate the signed negative-evidence sum in Eq. (5) independently in Python decimal at precisions 80 and 120, parsing serialized input digits directly. Form both ordinary prefix and single-deletion products from the immutable incidence lists. Re-run all three optimized implementations, retaining their original printed long-double digits; compare with the higher-precision direct answer in decimal arithmetic. Also compare the archived binary64 sparse output from each original round separately. Record absolute and relative discrepancies. Agreement between two working precisions is a check, not an interval proof.

The input hashes in cases.json and the binary hashes in binary_hashes.txt must match before measurement. A fresh destination is required on each run so that results cannot be mixed.
